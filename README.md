# Проект "Сервис для обмена знаниями"

### Регулярный запуск
* `. ./.venv/bin/activate` — если Linux/MacOS
* `. ./.venv/Scripts/activate` — если Windows
* `python start.py` — запуск проекта

---

### Возможности проекта
* Логин/регистрация пользователя в системе
* Возможность задать вопрос как сообществу так и Искусственному интеллекту
* Система поиска вопросов по заголовкам и тегам
* Возможность писать ответы на вопросы
* Система оценки ответов
* Система модерации и администрирования

---

### Технологии
* Python 3.12
* Django 5.2.12
* dotenv 0.9.9
* huggingface-hub 0.20.0
* python-dotenv 1.0.0

---

### Установка
* `git clone https://github.com/yourusername/knowledge-hub.git` — Клонирование
* `cd knowledge-hub`
* `python3 -m venv .venv` — создание виртуального окружения
* Активация виртуального окружения:
    * `. ./.venv/bin/activate` — если Linux/MacOS
    * `. ./.venv/Scripts/activate` — если Windows
* `pip install -r requirements.txt` — скачивание нужных библиотек
* `python start.py` — запуск проекта
