Введение
--------

Knowledge Hub - это веб-платформа для обмена знаниями, где пользователи могут:

- Задавать вопросы сообществу
- Получать ответы от других пользователей
- Общаться с искусственным интеллектом (AI)
- Оценивать качество ответов
- Модерировать контент
