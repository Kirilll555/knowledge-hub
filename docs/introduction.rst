Введение
========

Что такое Knowledge Hub?
------------------------

Knowledge Hub - это веб-приложение на базе Django для обмена знаниями и обсуждения вопросов.

Основные возможности
~~~~~~~~~~~~~~~~~~~~

- **Вопросы и ответы**: задавайте вопросы и получайте ответы от сообщества
- **AI интеграция**: получайте автоматические ответы от искусственного интеллекта
- **Оценивание**: оценивайте качество ответов (👍 / 👎)
- **Поиск**: полнотекстовый поиск по вопросам
- **Профили**: персональные профили с историей активности
- **Модерация**: система жалоб и администрирования
- **Блокировка**: система блокировки спамеров и нарушителей
- **Уведомления**: оповещения о новых ответах и событиях

Технологический стек
~~~~~~~~~~~~~~~~~~~~~

- **Backend**: Django 5.2.12, Python 3.12
- **Database**: SQLite (разработка), PostgreSQL (production)
- **Frontend**: HTML, CSS, JavaScript
- **Testing**: pytest, coverage
- **CI/CD**: GitLab CI
- **Documentation**: Sphinx
