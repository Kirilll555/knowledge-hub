Быстрый старт
=============

После установки
---------------

1. Откройте http://localhost:8000/ в браузере
2. Зарегистрируйтесь или войдите в аккаунт
3. Начните использовать платформу

Основные действия
-----------------

Задать вопрос
~~~~~~~~~~~~~

1. Нажмите кнопку **"Задать вопрос"** на главной странице
2. Заполните форму:
   - Название вопроса
   - Описание и контекст
   - Выберите категорию (опционально)
3. Нажмите **"Отправить"**

Ответить на вопрос
~~~~~~~~~~~~~~~~~~~

1. Откройте интересующий вас вопрос
2. Прокрутите вниз к разделу "Ответы"
3. Напишите ваш ответ в текстовое поле
4. Нажмите **"Отправить ответ"**

Оценить ответ
~~~~~~~~~~~~~~

- Нажмите **👍** для положительной оценки
- Нажмите **👎** для отрицательной оценки
- Вы можете изменить оценку в любой момент

Поиск вопросов
~~~~~~~~~~~~~~

1. Используйте поле поиска на главной странице
2. Введите ключевые слова
3. Нажмите Enter или кнопку поиска
4. Результаты появятся ниже

Редактировать свой профиль
~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Нажмите на иконку профиля в правом верхнем углу
2. Выберите **"Мой профиль"**
3. Нажмите **"Редактировать"**
4. Измените информацию и сохраните

Получить ответ от AI
~~~~~~~~~~~~~~~~~~~~~

1. На вопросе нажмите **"Получить ответ от AI"**
2. AI сгенерирует ответ за несколько секунд
3. Оцените качество ответа

Примеры использования
---------------------

Получить все вопросы через API
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    curl http://localhost:8000/api/questions/

Создать вопрос
~~~~~~~~~~~~~~~

.. code-block:: bash

    curl -X POST http://localhost:8000/api/questions/ \
      -H "Content-Type: application/json" \
      -d '{"title": "Вопрос", "content": "Описание"}'

Получить ответы
~~~~~~~~~~~~~~~~

.. code-block:: bash

    curl http://localhost:8000/api/questions/1/answers/

Оценить ответ
~~~~~~~~~~~~~~

.. code-block:: bash

    curl -X POST http://localhost:8000/api/answers/1/rate/ \
      -H "Content-Type: application/json" \
      -d '{"value": 1}'
