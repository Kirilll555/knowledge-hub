# Как внести вклад

## Форк и ветки
1. Форкните проект
2. `git checkout -b feature/название-фичи`
3. Коммитьте: `git commit -m "feat: добавлен поиск постов"`

## Коммиты
- Используйте Conventional Commits
- Пишите на русском
- Не больше 72 символов в заголовке

## Pull Request
- Опишите изменения

## Тестирование
`python manage.py test`

Спасибо за вклад!
