Вклад в проект
===============

Как внести вклад?
-----------------

Проект открыт для всех! Вот несколько способов помочь:

1. **Сообщить об ошибке** - создайте issue на GitHub
2. **Предложить улучшение** - обсудите в discussions
3. **Исправить баг** - создайте pull request
4. **Улучшить документацию** - обновите docs
5. **Помочь другим** - ответьте на вопросы

Начало работы
-------------

1. Форкните репозиторий
~~~~~~~~~~~~~~~~~~~~~~~~~~

Нажмите кнопку "Fork" на GitHub

2. Клонируйте свой форк
~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    git clone https://github.com/YOUR_USERNAME/knowledge-hub.git
    cd knowledge-hub

3. Создайте ветку
~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    git checkout -b feature/my-feature

Именование веток:

- ``feature/description`` - новый функционал
- ``fix/description`` - исправление ошибки
- ``docs/description`` - обновление документации

4. Установите зависимости для разработки
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    pip install -r requirements-dev.txt

5. Внесите изменения
~~~~~~~~~~~~~~~~~~~~~

Отредактируйте необходимые файлы.

6. Напишите/обновите тесты
~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    python manage.py test

7. Проверьте код
~~~~~~~~~~~~~~~~~

.. code-block:: bash

    pylint main/
    pycodestyle main/

8. Сделайте коммит
~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    git add .
    git commit -m "feat: add new feature"

Типы коммитов:

- ``feat:`` - новый функционал
- ``fix:`` - исправление ошибки
- ``docs:`` - документация
- ``test:`` - тесты
- ``refactor:`` - рефакторинг
- ``style:`` - стиль кода

9. Загрузите на GitHub
~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    git push origin feature/my-feature

10. Создайте Pull Request
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Нажмите кнопку "New Pull Request" на GitHub и заполните описание.

Требования к Pull Request
--------------------------

✅ **Обязательно**:

- Описание изменений
- Ссылка на связанную issue (если есть)
- Все тесты проходят
- Код соответствует PEP 8
- Нет конфликтов слияния

✅ **Рекомендуется**:

- Скриншоты для UI изменений
- Примеры использования
- Обновленная документация

Пример описания PR
~~~~~~~~~~~~~~~~~~~

.. code-block:: markdown

    ## Описание
    Добавил возможность загрузки аватара профиля
    
    ## Изменения
    - Добавлено поле avatar в Profile
    - Создана форма загрузки
    - Обновлен шаблон профиля
    
    ## Тесты
    ✅ Все тесты проходят
    
    ## Связанные issue
    Fixes #123

Рецензирование кода
-------------------

Код будет рецензирован разработчиком. Возможны запросы на изменения.

**Пожалуйста**:

- ✅ Отвечайте на комментарии
- ✅ Делайте изменения
- ✅ Пушьте обновления
- ✅ Просите пересмотреть

Кодовый стиль
--------------

Проект использует **PEP 8**:

.. code-block:: python

    # Хорошо ✅
    def create_question(user, title, content):
        """Создать вопрос.
        
        Args:
            user: автор вопроса
            title: название вопроса
            content: содержание вопроса
        """
        question = Question.objects.create(
            user=user,
            title=title,
            content=content
        )
        return question

    # Плохо ❌
    def createQuestion(usr,ttl,cont):
        q=Question.objects.create(user=usr,title=ttl,content=cont)
        return q
